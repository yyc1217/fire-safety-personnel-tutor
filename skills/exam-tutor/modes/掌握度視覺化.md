# 掌握度視覺化模式（自我定位地圖）

> exam-tutor 的模式檔。`SKILL.md` 之角色、資料來源與優雅退場照常適用。
> **本模式唯讀**：不出題、不批改，故 SKILL.md 之「先問後等再解」與「解答與批改」在本模式不觸發；`coverage` 由批改時累積，本模式**只讀不寫**。

觸發語：「掌握度」「熟悉度」「我對哪些科目比較熟／比較弱」「畫一下我的進度」或 `/fs-mastery`。把本機作答紀錄疊到題庫分類骨架上，畫成**各科目／主題／設備／法條的熟悉度文字條圖表**，供考前快速定位。**本模式唯讀：只讀不寫，絕不修改 `progress.json`**。

**輸出版面一律依 `${CLAUDE_PLUGIN_ROOT}/reference/輸出格式/掌握度圖表格式.md` 逐區塊比照**（該檔為此輸出的格式唯一真相：三種文字條樣式、規則與範例）；本節只規範內容面之計算模型：

1. 依 `${CLAUDE_PLUGIN_ROOT}/reference/user-config-spec.md` 載入 `config.json` 與 `progress.json`。**掌握度＝內容覆蓋度**：每個主題／法條／設備都有一份「相關內容清單」（分母），掌握度＝`progress.json` `coverage` 該項 `done`（已展現掌握之內容點）數 ÷ 該清單總數 ×100。**內容清單（分母）來源**：
   - 火災學主題＝`reference/索引/火災學主題知識點索引.md` 該主題知識點（`by_topic` 全部 19 主題列出）；
   - 消防安全設備＝`reference/索引/設備條文索引.md` **該設備條文列數＋文末「延伸知識考點」表中設備名完全相符之列數**（例：滅火器＝設置標準 6＋檢修基準 3＋延伸 1＝**10**，不是 9；**延伸考點漏算是實測發現過的錯誤**）。exam-tutor 當場自行擴充之延伸考點**不計入分母**，分母以索引已列出者為準（`by_equipment` 全部設備列出，設備歸屬系統以其題目所帶 `by_system` 判定或依索引分類）；
   - 消防法規＝**預設只列 `by_law` 前 5 大法規**（＋有作答紀錄的其他法規），其餘一行彙總、指名才展開；**條文骨架讀 `reference/索引/法規條文清單索引.md`，呈現時不重掃 statutes 全文**（前 5 以外之法規被指名時才當場讀該法 statutes）。每條 %＝`coverage["by_article:<條號>"]` 之 `len(done) ÷ total`（**分母是語意切分之獨立要點數，非項／款數**，如設置標準 §14 第一項第一款列甲類場所等多場所逐項計；`total` 由批改時存入）；`coverage` 無此條＝未接觸＝0%。條號 key 格式：增訂條文為「第 N 條之 M」（清單索引之 `N-M` 即此）、檢修基準為「第X章」（見 `user-config-spec.md`）。**該法整體 %＝該法各條 %（未接觸＝0%）之算術平均**——只用已存之 `done`／`total` 與清單索引條數即可算出，無需未作答條文之分母。
2. **尚未接觸一律以 0% 計**（非「未測」）。`weak_tally` 供弱點排序與「最弱前 5」；**呈現時只讀 `coverage`（分子 `done`、分母 `total` 或固定索引之總數）相除，不重掃 statutes／不重算**。
3. **末欄「覆蓋 {已掌握}／{總點數}」**：`已掌握`＝該項 `coverage.done` 數量、`總點數`＝內容清單總數；即掌握度百分比的計數形式。**除此欄外不再附加樣本數等內嵌文字**。
4. **範圍**：帶 `$ARGUMENTS`（科目／系統／設備／法規名）時只畫該段；未帶時畫火災學、消防法規、消防安全設備三大類。圖表末尾附「各科最弱考點」（**分科目列出**火災學／消防法規／消防安全設備各自的最弱考點，不混在一起；**消防法規之條文須附項目說明**，如 `設置標準 §18（應設水泡二惰鹵乾設備場所）`，取自 `reference/索引/設備條文索引.md`「項目」欄或該條 statutes 要旨）銜接 `/fs-weak`。
5. **無資料**（比照 SKILL.md「優雅退場」精神）：`weakness_tracking="none"` 或 `coverage` 尚為空→輸出全 `0%`／覆蓋 `0／{總點數}` 的完整骨架地圖並邀請先 `/fs-quiz`；`="notes"`→**先自己 Glob `<data_dir>/notes/*弱點筆記.md`** 取最近 5 份讀回（見 `user-config-spec.md`「`notes` 模式的跨對話接續」），僅就其涵蓋內容點粗估並明確標注「本圖以 notes 筆記粗估、非完整覆蓋度統計」；Glob 不到檔案時才請使用者提供。詳見格式檔「三、無資料時」。
6. **唯讀＋誠實標注**：本模式只讀不寫（`coverage` 由「解答與批改」累積，非本模式）；狀態列標明資料來源與統計期間；明示「掌握度為本機作答之覆蓋度統計，非官方能力認證」，呼應本 plugin 之影像辨識／OCR 免責文化。
