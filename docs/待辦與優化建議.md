## 待辦（進行中 🔄）

### 標籤分類校正（語意判斷為準）

**方針**：分類準確度一律以**語意判斷**為準。**系統／設備／法規／知識領域以各題 inline `🏷️` 標籤為唯一真相來源**；校正流程見 [`資料維護.md`](資料維護.md)。

**🔄 仍待語意校正（由使用者人工核對中）**：跨系統題系統歸屬是否齊全、多法條申論題 by_law 是否漏標、法規卷含設備計算者是否缺設備標籤、關鍵字誤命中之設備過度標記。校正後執行 `rebuild_index.py` 同步索引。

### 「熟悉法規」與「考前猜題」功能待使用者實測

**🔄 待使用者實測**：對照表數字之全面人工複核（已抽查，建議陸續核對）；`設備條文索引.md` 與原試算表逐列比對。

> **中文 command 檔名**（原列於本項）已查證官方文件收斂：skills 的 `name` 與目錄名**未設字元限制**（僅 `plugin init` 之 *plugin* 名稱不得含空白／路徑分隔），中文目錄名於規格上合規；結構正確性已由 CI 的 `claude plugin validate --strict` 把關。剩餘風險僅在終端輸入法與自動完成體驗，ASCII 備案保留但不必先做。

### Plugin 規格運用（2026-07-25 體檢，B 組：結構性改動待決）

A 組（版本策略、`allowed-tools`、CI、前置需求與授權說明）已於 v0.9.0 完成；`exam-tutor` 模式拆檔已於 v0.10.0 完成，見 [`../CHANGELOG.md`](../CHANGELOG.md)。以下待使用者決定方向後再動：

- **🔄 導入 `userConfig`**：`plugin.json` 可宣告 `level`／`data_dir`／`weakness_tracking`，由 Claude Code 於啟用時跳設定對話框，skill 內以 `${user_config.KEY}` 直接取值，省去各 skill 自行實作的「初次詢問流程」。需同步改寫 `reference/user-config-spec.md`。
- **🔄 `context: fork`**：`/出考卷`（純產出、無需來回問答）最適合放進 subagent，`/猜題` 第二段次之，避免 5–8 分鐘的重工作污染主對話。
- **🔄 安裝體積 265 MB**：`statutes/原始檔案/` 55 MB＋`corpus/pdf/` 37 MB。v0.9.0 已先於 README 誠實標示；是否進一步把大型 PDF 改掛 GitHub Release 資產或獨立 repo，取決於能否接受「原卷改為線上取得」。
